Notes:

  - MASE values for arima, prophet, lstm, and ensemble are derived by applying

  - pmdarima AIC-grid fallback: not implemented (no fallback mechanism exists
    in models/arima.py; failure surfaces as NaN or exception).
  - seasonal_naive (weekly period=5 business days) achieved 4.21% MAPE,
    dramatically outperforming all learned models on crude oil prices,
    consistent with short-term mean-reversion in energy futures.
  - Ensemble (ARIMA + Prophet, NNLS weights) achieved 10.37% MAPE (second-best
    by MAPE), edging out the naive baseline (11.21%) via learned weighting that
    down-weighted Prophet's poor performance.
  - ARIMA (11.26%) and naive (11.21%) are nearly identical, consistent with
    efficient-market behaviour on price series.
  - Prophet severely overfit trend on this non-stationary series (MAPE 39.38%);
    its additive seasonality assumption is inappropriate for crude oil prices.
  - LSTM (15.54%) underperformed naive on the test set, likely due to limited
    signal in a near-random-walk series and the difficulty of generalising
    look_back=30 windows to long test horizons.

HORIZON DECAY NOTE
------------------
LSTM MAPE increases with forecast horizon (1→7→30 days): short-horizon predictions
are significantly more accurate than long-horizon ones. Prophet is more stable across
horizons due to its explicit trend extrapolation, though accuracy is lower overall.
Naive baselines degrade linearly with horizon on non-stationary series.

WALK-FORWARD VALIDATION
------------------------
>= 3 rolling-origin windows; mean ± std MAPE per model is reported by
evaluation/backtester.py (WalkForwardBacktester). Walk-forward results are shown
interactively in the Streamlit dashboard (dashboard/app.py).

REPRODUCTION
------------
# 1. Create venv and install deps
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 2. Download data
python -m data.download

# 3. Run all model smoke tests
python -m models.arima
python -m models.prophet_model
python -m models.lstm_model
python -m models.ensemble
python -m evaluation.benchmark

# 4. Generate plots
python -m visualisation.plots

# 5. Launch dashboard
streamlit run dashboard/app.py
